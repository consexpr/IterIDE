# 题目存储

Windows 正式版的配置目录为 `%APPDATA%/ITER`，题库目录为 `~/.iter`。首次启动时，在新目录尚不存在的情况下迁移旧版本数据，并保留原目录；已有 ITER 数据不会被覆盖。指定 `ITER_DATA_DIR` 或 `ITER_STORE` 的隔离运行不读取默认旧题库。

一份 `.cpp` 对应一道题。配置统一放在 `~/.iter`（测试可用环境变量 `ITER_STORE` 指定其他目录），不再新建代码旁的侧车目录。

- `index.json`：题目 ID 到解答最后已知绝对路径的索引。
- `problems/<id>/problem.json`、`tests/`：评测配置、复制的测试与附加 checker/interactor/grader 文件。
- `problems/<id>/code.cpp`：代码快照，每次保存配置、写测试及编辑器调用 `snapshotCode` 时更新。
- `problems/<id>/snapshots/index.json`、`snapshots/<快照 ID>.cpp`：用户保存的多版本代码快照，索引只保存名称、时间、大小和行数，正文按需读取。沿用程序文件的身份，与同名文件、其他程序隔离。
- `problems/<id>/meta.json`：ID、解答路径、标题及创建/更新时间。

Windows 在源文件的 NTFS ADS `:iter.id` 中记录 ID；不改变 C++ 内容，并保留可见修改时间。macOS/Linux 尝试用系统自带工具读写 `user.iter.id` 扩展属性；工具或文件系统不支持时，静默退回精确路径绑定。

| 操作                               | 配置与测试                                                     |
| ---------------------------------- | -------------------------------------------------------------- |
| 同一卷移动/改名，ID 保留           | 沿用原题目，更新索引                                           |
| 复制代码，ID 也复制，原文件仍存在  | 分配新 ID，并复制中央题目数据，之后互不影响                    |
| ID 丢失，仍在原路径                | 从精确路径索引重新绑定，并尝试补回 ID                          |
| ID 丢失后移动，或跨机器只传 `.cpp` | 创建新题目，不猜测旧身份                                       |
| 删除代码                           | 中央数据保留，界面不再提供恢复入口                             |
| 新建文件首次保存                   | `moveSource`：同一份数据改绑到新位置；目标位置原有的数据被替换 |
| 放弃新建文件                       | `discardSource`：删除托管文件及其中央数据                      |
| 从题库移除                         | 只删除中央题目目录和索引，不删除用户代码或链接数据             |

未保存的新建文件是 `~/.iter/untitled/Untitled-N.cpp`（真实文件，运行与调试照常）。会话 `session.json` 在用户数据目录，记录各标签的路径、缓冲区与上次保存的文本。

右侧「快照」页提供保存、预览、重命名、恢复和删除。默认 `Ctrl+Alt+S` 保存当前编辑内容（包含未落盘的修改），快捷键可在设置中更改。首次保存或保留身份的改名沿用原历史；放弃未命名程序时，其快照随托管数据一起删除。此功能仅保存代码，不记录评测配置或测试数据，也不参与云同步。

快照读写与文件身份迁移共用存储锁，正文先落盘、索引原子发布；索引损坏时停止写入并保留原文件。恢复先将当前缓冲区另存为「恢复前自动保存」，成功后以一次可撤销的编辑替换正文。期间发生输入、切换文件、关闭或进入调试就取消替换；备份失败也不会修改代码。预览限制为 2,000 行或 100,000 字符，恢复使用完整正文。

链接测试记录绝对路径，解答移动后仍读取原数据；编辑链接测试会复制到中央目录，不修改原数据。外部评测文件仍遵守 `relativeTo` 契约；解答单独移动时会固定其原路径。旧源码旁的题目侧车目录首次加载时复制迁移，原目录保持不动。
